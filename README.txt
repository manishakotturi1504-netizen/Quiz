# QuizMaster - Small Quiz Application

## How to run
1. Extract the ZIP folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No installation or server is required.

## Demo Admin Login
Username: admin
Password: admin123

## Main features
- Admin and Student roles
- Admin question creation, editing and deletion
- Basic, Intermediate and Hard difficulty levels
- Quiz time setting
- Accurate countdown based on the real quiz start timestamp
- Timer continues while navigating questions
- Automatic submission when time expires
- Student score, percentage, correct/wrong/unanswered results
- Student results visible to Admin
- localStorage persistence
- Bootstrap 5 responsive UI
- CSS/JavaScript animations
- Beginner-friendly sample questions

## Important
This is a frontend/localStorage demonstration application. The admin login is not secure enough for production because credentials and data are stored in browser-side JavaScript/localStorage. For a real college/project deployment, connect it to a backend and database.
